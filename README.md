# What's On

Une application web utile et responsive pour consulter la météo, les horaires du tram et l'agenda des événements à Blagnac conçu pour les étudiants.


## Tester l'application

[![Demo](https://img.shields.io/badge/Demo-Live-success?style=for-the-badge&logo=github)](https://emispheres.github.io/Whatson/)


## Fonctionnalités

- **Météo en temps réel** - Données actualisées via l'API Open-Meteo
- **Horaires du Tram T1** - Affichage des départs vers Aéroconstellation et Palais de Justice
- **Agenda** - Intégration du calendrier Google de l'IUT
- **Mode sombre** - Thème clair/sombre avec détection automatique des préférences

## Technologies Utilisées

- **HTML5** - Structure sémantique
- **CSS3** - Design moderne avec variables CSS, Flexbox et Grid
- **JavaScript Vanilla** - Navigation SPA, gestion d'état
- **APIs REST** - Open-Meteo, Google Calendar
- **Font Awesome 6** - Icônes modernes
- **Google Fonts** - Police Inter

## Responsive Design
